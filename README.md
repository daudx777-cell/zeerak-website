# ZEERAK SERVICES — B2B Industrial Fire Safety & Compliance Platform

High-performance, Swiss-industrial web platform for **ZEERAK SERVICES** (Established 2010, Karachi, Pakistan).

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens
- **Typography**: Archivo (Variable wdth) & Figtree
- **Language**: TypeScript

## Project Architecture
- `src/data/zeerakData.ts`: Verified single source of truth for company facts, services, audit matrices, and verified client roster.
- `src/components/layout/Header.tsx`: Swiss industrial navigation with high-contrast Signal Red brand shield.
- `src/components/home/Hero.tsx`: Architectural hero section with macro hardware showcase and operational proof bar.
- `src/components/home/CoreSystems.tsx`: Scroll-synced, GPU-accelerated 01–04 system ledger with blueprint entrance animations.

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
